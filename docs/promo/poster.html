What it does
04
01

破甲System-layer injection

把客户端自带 system 整段替换成你的指令，三种拼装：replace / append / prepend。Claude Code 的 base prompt 是成体系的反注入规程，实测只有 replace 过得去；代价是身份丢失，用落款把名字锁回来。单层原则：同一指令出现两次即自证注入，所以不写 AGENTS.md / CLAUDE.md。

02

模型按所选路由Model passthrough

客户端选什么就走什么：cn:* 原样透传，claude-* 映射到默认模型，其余回落。/v1/models 镜像上游真实目录，选择器里看到的就是能用的。

03

长思考不再哑火No silent empty answers

推理模型会烧空 max_output_tokens：预算抬到 16000 起，流里 10 秒一次心跳，真空产出返回 response.failed 说明原因，而不是假装完成。

04

权限与自愈Permissions & supervision

权限档位一并落地：Codex approval_policy=never + danger-full-access，Claude bypassPermissions。桥死了 5 秒重生，spawn 前先查端口，多副本不会互抢。
